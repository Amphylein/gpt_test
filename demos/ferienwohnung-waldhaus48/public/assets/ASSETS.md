# Coherence note

The demo intentionally represents **three different apartments**, so the interiors are allowed to differ. The coherence comes from:

- restrained natural materials
- timber/stone/neutral colors
- natural window light
- absence of ornate hotel styling
- recurring forest views / landscape context

The regional images are all Germany/Baden-Württemberg focused, with multiple assets explicitly tagged as Black Forest locations on their source pages.

# Repository note

Binary images are not committed by the connected text-file workflow. Run one of the included asset scripts to download the documented files to `public/assets/images/` before previewing locally.
