# Research Method

## Purpose

This repository is not a gallery of pretty sites. It is a working research base for building original commercial demos that feel authored by a designer rather than generated from a generic prompt.

## Selection criteria

A reference site is useful when it succeeds in several of these areas:

- immediate category clarity
- strong real photography
- deliberate typography
- recognizable brand character
- logical mobile-first information hierarchy
- clear next action
- strong trust signals
- good service or property explanation
- low-friction booking/contact path
- restrained, purposeful motion
- useful local context
- copy that sounds specific to the business

A site can still be included if it is weak in one area but exceptional in another. The analysis explicitly separates **what to learn** from **what not to copy**.

## Research sources

Discovery uses a mixture of:

- current live business websites
- recent 2026 design roundups
- industry-specific conversion audits
- direct inspection of the live site structure and copy

Roundups are only discovery aids. Their rankings are not accepted at face value.

## Audit dimensions

Each reference is judged on:

### 1. First five seconds
Can a visitor answer:

- What does this company offer?
- Where does it operate?
- Why should I trust it?
- What should I do next?

### 2. Visual hierarchy

- headline scale
- image dominance
- spacing rhythm
- contrast
- alignment
- section pacing
- visual repetition

### 3. Photography

- real vs stock
- environmental vs staged
- detail vs wide shots
- people vs product/project
- consistency of lighting and grading

### 4. Copy

- specificity
- evidence
- tone
- jargon level
- amount of text
- whether claims are believable

### 5. Conversion

- primary CTA
- CTA repetition
- phone/booking visibility
- form friction
- trust near decision points
- price/availability transparency where relevant

### 6. Business-specific UX

Different categories require different answers:

- Handwerk: service area, project proof, trust, quote path
- Ferienwohnung: images, occupancy, amenities, rates, availability, booking
- Friseur/Kosmetik: services, price framing, team, booking, atmosphere
- Werkstatt: trust, services, opening hours, phone, appointment, diagnostics

### 7. Anti-template character

We look for choices that make the site feel authored:

- unusual but coherent type pairing
- category-specific layout grammar
- strong art direction
- branded copy rhythm
- asymmetric composition
- controlled motion
- meaningful use of white space

## Rule for synthesis

Never copy a complete section composition from a single reference.

Instead, a demo should combine principles from several references. Example:

- conversion clarity from Reference A
- photography pacing from Reference B
- typography restraint from Reference C
- booking UX from Reference D

The result must be a new composition.
